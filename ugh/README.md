# ugh

A minimal workout timer PWA. Mainly designed for EMOM (Every Minute On the Minute) kettlebell workouts.

## What it does

Runs timed workout rounds. Tap to start, pause, or resume. Shows current round and time remaining.

## Usage

Open `index.html` in a browser. Tap anywhere on the screen to control the timer.

## Installation

As a PWA, you can install it to your home screen from most mobile browsers.

## Files

- `index.html` - Main structure
- `css/style.css` - Styles
- `js/app.js` - Entry point
- `js/workout.js` - Workout state
- `js/timer.js` - Timer logic
- `js/history.js` - Session storage
- `js/ui.js` - UI updates
- `manifest.json` - PWA config
