# Dubay

A web-based tool for analyzing italic handwriting patterns based on the Dubay method.

## Features

- Analyzes text to identify handwriting join patterns (speed joins, hooks, bridges, e-loops)
- Identifies frequently used words for practice
- Categorizes letter combinations by join type
- Print-friendly analysis reports

## Usage

Open `index.html` in a browser. Paste text to analyze, and the tool will automatically generate a breakdown of joins and patterns to practice.

## PWA

Installable as a progressive web app for offline use.
