# Project: Mental Scratchpad PWA

## Overall Goal
To develop a high-speed "mental scratchpad" for daily use by combining the **Major System (1-100 pegs)** with a standardized visual vocabulary (**Phosphor Icons**). 

The objective is to train the brain to encode and decode information fast enough to use in real-time conversations and meetings. By paginating memory into blocks of 10 pegs and using a specific "practice material" (e.g., imagining all practice pegs made of splintery Wood) versus "real-world material" (e.g., Metal), the system completely avoids the "dirty memory palace" problem (proactive interference). The end result is reliable, fast, Random Access Memory (RAM) for daily tasks.

---

## Training Modes

### Mode 1: Major System Mastery (The Index)
* **Purpose:** To achieve zero-friction, instant translation between a Number (1-100) and its Major System Peg Word.
* **Mechanics:** An Anki-style flashcard interface. The app displays a giant number. The user mentally retrieves the peg word, taps the screen to reveal the correct answer, and strictly self-grades (Pass/Fail) to advance. 
* **Why it works:** Removes the friction of mobile typing, allowing for rapid 50-card drills in under a minute.

### Mode 2: Visual Sequencing (The Ink)
* **Purpose:** To build the working memory muscle for holding abstract, standardized shapes without relying on verbal labels. 
* **Mechanics:** The app shows a sequence of random Phosphor icons one by one. During the recall phase, the user must select the icons in the exact order they appeared from a massive grid of 100 icons.
* **Why it works:** Warms up the visual cortex and trains the brain to perceive shapes rather than words, which is required for high-speed encoding.

### Mode 3: RAM Combination (The Crucible)
* **Purpose:** The actual simulation of the mental scratchpad. Trains the "glue" (bizarre, 3D interaction) between the Index (Peg) and the Data (Icon), and tests random-access retrieval.
* **Mechanics:** * *Encoding:* The app generates a sequence of random Pegs paired with random Icons (e.g., "34 - Mower" + "Floppy Disk"). The user has a few seconds to visualize the interaction using their designated practice material (Wood).
    * *Decoding (The RAM Test):* The app tests retrieval out of order (e.g., "What was at 88?"). 
    * *The Ghost Peg:* Crucially, the test includes "trick" questions—asking for the contents of a Peg that was never encoded. The user must confidently declare "Slot is Empty" to prove they aren't hallucinating data.
* **Why it works:** Proves the memory is anchored entirely to the specific peg address, not to a sequential chain, ensuring reliable retrieval under real-world pressure.
