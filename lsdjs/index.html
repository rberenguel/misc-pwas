Game Boy Audio Processing & Channel Hardware

The DMG-01 has four hardwired sound channels. Each has fixed registers and fixed limits. LSDJ works around those limits with frame tables. You get arpeggios, pitch bends, and detuned basses that the raw hardware cannot produce alone.

Channel Bandwidth & Functional Domain

Pulse 1 & Pulse 2 Channels

Two square-wave channels. Use them for melody, arpeggios, and chords.

Duty: 12.5%, 25%, 50%, 75%
Vol Resolution: 4-Bit (16 steps)
Pitch Sweep: Pulse 1 Native Sweep
Polyphony: Monophonic each
Wave Channel (Custom Synth)

32 4-bit samples per wave. Lower range than Pulse. Use it for sub-bass.

Mode: DRUM (Logarithmic Slide)
Waveform: Sine, Square, User RAM
Sub-Bass Reach: Down to C-0 / 16Hz
Vol Control: 4 fixed levels
Noise Channel (Pseudo-Random)

Pseudo-random noise from a 15-bit shift register. Use it for drums and effects.

Shape Parameter: High (Hiss) / Low (Crunch)
Envelope: 4-Bit Hardware Vol
Primary Role: Percussion & FX
Table Pitch: S / P Pitch shift

Composition Workflow & Table Command Cheat Sheet

Do not lose momentum designing instruments. Pick a channel, set an envelope, choose a shape, and attach a table. The command reference below shows how to change the sound on every frame.

1

1. Pick Channel & Envelope

Pulse does leads and chords. Wave does sub-bass and kicks. Noise does percussion. For a pluck, set Initial Vol to D or E. Set Sweep to 1 or 2.

PULSE Envelope: C2 / A7
NOISE Envelope: D1 / EC
2

2. Set Duty Cycle / Shape

Pulse: 50% sounds hollow. 25% sounds like a guitar pluck. 12.5% sounds like a synth bass. Noise: higher shape values sound brighter.

WAVE DUTY: 50% (Hollow) / 25% (Pluck)
NOISE SHAPE: FC (Kick) / 55 (Hi-Hat)
3

3. Attach Table Sequence

Attach a Table to the instrument. Step 00 can drop the pitch for a kick or run an arpeggio. The main track stays clean.

Table 00: Pitch Sweep (S F0)
Table 05: Arp (C 04, C 07)
